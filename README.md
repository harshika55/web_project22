# Web Technology | Learning Portal

A complete, interactive learning portal for understanding **Web Technology** (B.Tech Computer Science and Engineering). This portal is organized unit-wise with detailed study notes, examples, and examination questions for students.

---

## 📌 Features

- **Unit-Wise Structure:** Covers 5 comprehensive units ranging from Internet Basics to Decentralized Web (Web 4.0).
- **Interactive Topics:** Detailed academic notes with definitions, history, workflows, advantages, disadvantages, and important exam questions.
- **Responsive Design:** Dark-themed UI optimized for both desktop and mobile devices.
- **Dynamic Navigation:** Smooth single-page application (SPA) style navigation between Home, Chapters, Topics, and Notes.

---

## 📚 Course Curriculum (Units)

1. **Internet and Web Basics** (Internet, WWW, Protocols, DNS, Web Servers, etc.)
2. **HTML, JavaScript, CSS and XML** (HTML elements, DHTML, CSS, XML Schemas, DOM, SAX)
3. **Web Services and AJAX** (SOAP, WSDL, UDDI, AJAX Applications)
4. **Web 2.0 and Semantic Web** (Features, Social Networking, RDF, Ontology)
5. **Web 4.0 and Decentralized Web** (Blockchain and Future of Web Technology)

---

## 🛠️ Technologies Used

- **HTML5** (Structure)
- **CSS3** (Styling & Layout variables)
- **JavaScript (ES6+)** (Dynamic rendering and SPA routing logic)

---

## 🚀 Getting Started

To run this project locally on your system:

1. Clone or download this repository.
2. Open the project folder in **Visual Studio Code**.
3. Open `pro.html` using the **Live Server** extension in VS Code.
